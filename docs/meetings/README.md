# Meeting notes

One file per meeting: `YYYY-MM-DD.md`, using this template.

```
# Meeting YYYY-MM-DD — note-taker: <name>
Attendees:
## Done since last meeting (link Jira keys)
## This week's "done when" check: pass / fail
## Decisions
## Risks / warning signs
## Actions (owner, Jira key, due)
```
